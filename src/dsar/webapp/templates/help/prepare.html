Before anyone reviews, the operator turns the exported data (Microsoft Purview exports, files supplied by teams, database extracts) into passages scored for personal data about the subject. This is done in the terminal. The Pipeline table on the case page shows each stage's last status from the audit log.

Run order

CommandWhat it does
1dsar audit note "Case … opened"Starts the case's audit log: controller, operator, machine.
2dsar manifestHashes the export before and after extraction, so it can be shown the data wasn't changed.
3dsar attachmentsTakes the attachments out of the mailboxes.
4dsar ingestReads every file into passages in the case database.
5dsar provenanceChecks each file against the manifest and records where it came from.
6dsar qa ingestChecks every file is accounted for. Read every low-yield file it lists by hand.
7dsar model-checkChecks the local model is accurate and isn't cutting text short.
8dsar classifyScores every passage 0–10 for personal data about the subject. Long: it resumes if stopped.
9dsar verify-evidenceRe-checks that every high score quotes text really in the passage.
10dsar qa classifyChecks the scores and sends a sample for a person to score blind.

Add --config <case config> to each command. The full run-book, including the model settings: docs/OPERATIONS.md.

What the scores mean

ScoreMeaning
0–5Little or nothing about the subject. Not reviewed unless you choose to.
6–7Specific personal information: contact details, dates, HR or study actions.
8–9Opinions about the subject's conduct or performance, complaints.
10Highly opinionated, derogatory or sensitive remarks.

Items and paragraphs scored {{ min_score }} or more need a reviewer's decision. A score is a pointer, never a decision: the model can be wrong in both directions.

Reading the original

The Mail viewer and Teams viewer open a mailbox from the case as its owner saw it. In a case they open only mailboxes listed in the manifest, after checking the file hasn't changed. Anything you save goes read-only into the case's output/toolbox/ folder and is logged with your name.
